# SvintusClient

Fabric 1.21.11.

## Шаги
1. JDK 21.
2. Шрифты Inter (400/600 latin+cyrillic) → src/main/resources/assets/svintusclient/fonts/
   Имена: inter-latin-400.ttf, inter-latin-600.ttf, inter-cyrillic-400.ttf, inter-cyrillic-600.ttf
3. Java-файлы → src/main/java/com/lowcode/svintusclient/...
4. ./gradlew build
5. jar в build/libs/
